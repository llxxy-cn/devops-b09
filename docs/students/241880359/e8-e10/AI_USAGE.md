# AI 使用记录

工具：Codex 对话助手。

用途：解释参考实现与终端输出，提供三种补丁检查命令、
重复报告测试、去重修改脚本、交付报告保存与打包命令，
并协助整理个人文档草稿。

人工操作：学生在服务器执行命令并回传真实终端输出。
实现与测试代码包含 AI 辅助生成内容。

验证：修复前重复记录导致三个风格子案例失败；
修复后全部 10 个测试方法通过；
三种 Patch 可应用检查通过、原样例 Git 工作区干净；
报告与项目版本、Patch、计划核对一致。

排错：一次报告保存命令因容器默认用户与样例所有者不同，
触发 Git dubious ownership。改用宿主机 UID/GID 后成功，
没有关闭 Git 所有权检查。

候选 Patch 由课程确定性 patch() 函数生成，
没有调用外部 LLM 服务自动生成修复。
A 组真实接口、E10 和 CI 尚未执行，不记为已验证。
