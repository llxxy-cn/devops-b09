# ADR：B2 对重复缺失依赖报告按目标与依赖去重

## 决定

在 patch() 单次调用内维护 seen 集合，
以 (target, dependency) 为键，仅处理首次出现的 MISSING 记录。
保留输入顺序，不处理 REDUNDANT，候选生成阶段不写回源项目。

## 理由

重复报告不应导致依赖重复追加或修改计划重复记录。
目标也参与去重，避免把不同目标对同一头文件的需求误认为重复。
继续沿用原有版本检查、路径检查和三种风格的修改位置选择。

## 代价与边界

该改动只处理同一报告中的重复目标依赖对。
不保证共享变量被多个目标引用时没有额外影响，
不提供任意 Makefile 解析能力，也不替代 E10 质量验证。
