# AI 使用记录

工具：Codex 对话助手。

## 使用范围

AI 用于解释课件任务、检查仓库结构、整理 B3 工作计划、生成终端命令
草稿、辅助编写编译失败测试与交付验证脚本，以及整理本次个人文档。

候选 Patch 由课程仓库中的确定性 `patch()` 函数生成，不是由外部
大模型直接修改 Makefile。

## 人工操作与验证

学生本人完成个人分支创建，在服务器执行 Docker、Git、测试和实验命令，
并逐次回传真实输出。学生本人接收 B2 包、校验 SHA256、保留样例 Git
历史并运行六场景验证。

实际验证结果包括：

- 个人 E8、E9、E10 命令退出码均为 0；
- E10 三个质量门场景全部通过；
- B2 交付扩展矩阵六个场景全部通过；
- 完整发现模式下 11 项单元测试全部通过；
- direct、macro、mixed 接受后经 BuildChecker 复扫均无 `MISSING`。

## AI 辅助排错记录

- 首次通过 heredoc 向容器传入 Python 时遗漏 `docker run -i`，容器未接收
  标准输入；补加 `-i` 后成功生成并核对三份 E9 报告。
- 服务器连接 GitHub 不稳定且账户密码不能用于 Git 操作，因此将提交制作
  为完整 Git Bundle，下载到本地后校验两端 SHA256 一致，再导入本地仓库。
- `git diff --check` 对证据 CSV 的 CRLF 和统一 Patch 中的 Makefile 制表符
  给出空白提示；这些文件作为原始生成证据保留，没有为消除提示而改写。
