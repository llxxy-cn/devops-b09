# Tiny Greeting

A small C command-line application. A C compiler and GNU Make are required.

Build with `make`. Run `./hello`; the exact output must be `hello E3`.

This is a course-authored fixture, not an original paper benchmark.

## E11-E12 B1 real project

Build and verify the project with:

```bash
make clean
make
make test
./app
```

The expected program output is `hello E3`.
